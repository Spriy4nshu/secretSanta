# Secret Santa Web App

Next.js web application for Secret Santa gift exchange.

## Getting Started

### Prerequisites
- Node.js >= 18
- Yarn

### Installation

From the root directory:
```bash
yarn install
```

### Running the App

Development server:
```bash
cd apps/web
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building

```bash
yarn build
yarn start
```

## Tech Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
